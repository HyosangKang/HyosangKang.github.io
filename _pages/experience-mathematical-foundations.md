<p class="project-intro">
  Mathematical foundations asks how mathematical objects are defined and what
  rules make them work. It looks beneath familiar calculations to study axioms,
  logic, abstraction, representation, and proof.
</p>

These projects use programming as a way to make definitions precise. Students
can build number systems from simple operations, express mathematical
behaviour through Go interfaces, compare different representations of the same
object, and test which laws a program can enforce. Writing the code exposes
assumptions that are easy to leave hidden on paper.
