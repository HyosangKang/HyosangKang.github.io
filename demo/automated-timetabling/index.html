What the engine is doing

Try, detect a dead end, then change the backward step.

If a course cannot be placed, DATA does not always undo just the last choice. It grows the backward distance and moves the difficult course earlier in the order. The next attempt therefore changes a wider part of the partial timetable instead of repeating the same short loop.
